# Employee_Management_Java
A console-based Employee Management System built using Java to manage employee records through a simple menu-driven interface.

Features
Add Employee
Remove Employee
Update Employee details
Search Employee by ID
View all Employees
Find Highest Salary Employee
Calculate Total Salary
Save employee data to a file
Load previously saved employee data
Exit the application
Technologies Used
Java
OOP Concepts
ArrayList
Serialization
File Handling
Scanner
OOP Concepts Used
Encapsulation using private fields and getters/setters
Classes and Objects
Constructors
Method Overriding (toString())
Interface implementation (Serializable)
How It Works

The application provides a menu with different operations. Users can enter employee details through the console, and the data is stored in an ArrayList<Employee>.

Employee data can also be saved into employees.dat using Java Serialization and loaded again when required.

Run the Project

Compile:

javac Main.java

Run:

java Main
